# thai-egp

[English](README.en.md) · จากคนทำ [data-go-th](https://github.com/nuttakulsv/data-go-th) (ค้นและแก้ไฟล์ข้อมูลเปิดภาครัฐชุดอื่น) และ [awesome-thai-api](https://github.com/nuttakulsv/awesome-thai-api)

อยากรู้ว่าเทศบาลแถวบ้านจ้างใครทำถนน ปีที่แล้วโรงพยาบาลจังหวัดซื้อยาจากใคร หรือบริษัทที่ได้งานรัฐมากที่สุดในประเทศคือใคร ทุกเรื่องนี้มีคำตอบอยู่ในข้อมูลเปิดของรัฐอยู่แล้ว กรมบัญชีกลางกับสำนักงานพัฒนารัฐบาลดิจิทัลปล่อยข้อมูลจัดซื้อจัดจ้างจากระบบ e-GP ทุกสัญญาตั้งแต่ปีงบประมาณ 2558 ไว้บน data.go.th ให้โหลดฟรี เป็นข้อมูลชุดเดียวกับที่เว็บ [ภาษีไปไหน](https://govspending.data.go.th) ใช้

ปัญหาคือไฟล์ CSV พวกนั้นเปิดแล้วใช้ต่อไม่ได้เลย ไฟล์ละ 500 MB ปีละสิบกว่าไฟล์ แต่ละปีมีคอลัมน์ไม่เท่ากัน ปี 2568 บอกชื่อคอลัมน์ไว้ไม่ตรงกับข้อมูลจริง ถ้าเปิดด้วย pandas ตรงๆ ชื่อผู้ชนะจะไปตกอยู่ในช่องละติจูด

thai-egp ดึงข้อมูลจาก data.go.th แก้ปัญหาพวกนี้ แล้วใส่ลง SQLite ให้ในคำสั่งเดียว ค้นหาได้ จัดอันดับได้ และมีชุดสัญญาณผิดปกติให้ใช้เป็นจุดเริ่มต้นตรวจสอบต่อ เขียนด้วย Python ล้วน ไม่ต้องลงอะไรเพิ่ม

```
$ egp search ถนน --province เชียงใหม่ --year 2567
...
67059412082  59,800,000 บาท  ประกวดราคาอิเล็กทรอนิกส์ (e-bidding)  2024-07-12
  ประกวดราคาจ้างก่อสร้างงานปรับปรุงทางเพื่อความปลอดภัย ถนนสาย ชม.3029 ถนนสมโภชเชียงใหม่ ๗๐๐ ปี ...
  แขวงทางหลวงชนบทเชียงใหม่, เชียงใหม่ -> บริษัท โฟร์เอ็ม อินเตอร์เทรด จำกัด
```

## ติดตั้ง

ต้องมี Python 3.9 ขึ้นไป

```
pip install git+https://github.com/nuttakulsv/thai-egp
```

หรือโหลดไฟล์เดียวมาใช้ก็ได้: `curl -O https://raw.githubusercontent.com/nuttakulsv/thai-egp/main/thai_egp.py` แล้วเรียก `python3 thai_egp.py` แทน `egp`

## เริ่มใช้

```
egp years                       # ดูว่ามีข้อมูลปีไหนบ้าง และไฟล์ใหญ่แค่ไหน
egp load 2568                   # ดึงทั้งปีจาก data.go.th ลง egp.sqlite (ไม่เก็บไฟล์ดิบ)
egp load 2566 2567              # เพิ่มปีอื่นเข้าไปในฐานข้อมูลเดิม
```

`load` อ่านข้อมูลจาก data.go.th ทีละไฟล์แล้วใส่ฐานข้อมูลเลย ไม่ต้องมีที่เก็บไฟล์ CSV ถ้าเน็ตหลุดกลางทาง ไฟล์นั้นจะถูกยกเลิกทั้งไฟล์ สั่งใหม่จะทำต่อจากไฟล์ที่ค้างอยู่ ฐานข้อมูลใช้พื้นที่ราว 1.6 KB ต่อแถว ถ้าอยากเก็บไฟล์ดิบไว้ด้วย ใช้ `egp download 2568` แล้วค่อย `egp load egp-data/2568/*.csv`

```
egp search ซ่อมถนน หมู่ 5 --dept "เทศบาลตำบลแม่ริม"     # คำในชื่อโครงการ ต้องเจอทุกคำ
egp search --winner "ก่อสร้าง" --min 10000000 --year 2568
egp top winner --year 2568                              # ใครได้เงินมากที่สุด
egp top dept --province ขอนแก่น                          # หน่วยงานไหนใช้เงินมากที่สุด
egp top method --year 2568                              # สัดส่วนแต่ละวิธีจัดซื้อ
egp flags --province ลำปาง                               # สัญญาณที่ควรดูต่อ
```

ทุกคำสั่งใส่ `--csv` เพื่อเอาผลไปเปิดใน Excel หรือ Google Sheets ได้ และใช้ `sqlite3 egp.sqlite` เขียน SQL เองได้ ตารางหลักชื่อ `contracts`

## ใครได้งานรัฐมากที่สุดทั้งประเทศ

```
egp winners
```

คำสั่งนี้อ่านข้อมูลทุกปี (ราว 50 GB) จาก data.go.th แล้วสรุปเป็นรายบริษัทลงไฟล์ `winners.csv` โดยไม่ต้องสร้างฐานข้อมูล เครื่องที่ดิสก์เหลือน้อยก็ใช้ได้ ใช้เวลาเป็นชั่วโมงตามความเร็วเน็ต ถ้าหยุดกลางทาง สั่งใหม่จะข้ามไฟล์ที่เสร็จแล้ว

ในไฟล์มียอดเงินรวม จำนวนสัญญา จำนวนและยอดเงินของงานวิธีเฉพาะเจาะจง (และวิธีตกลงราคาตามระเบียบเดิมก่อนปี 2560) ปีแรกกับปีล่าสุดที่ได้งาน หน่วยงานที่จ้างมากที่สุด 3 แห่ง เลขนิติบุคคล และลิงก์หน้าบริษัทบนระบบ DBD DataWarehouse ของกรมพัฒนาธุรกิจการค้า ซึ่งเปิดดูรายชื่อกรรมการได้

นับเฉพาะนิติบุคคล บุคคลธรรมดาไม่อยู่ในไฟล์นี้ สัญญาที่ยอดเงินเกินงบประมาณเกินสองเท่า (ส่วนใหญ่คือพิมพ์ตัวเลขผิด) จะไม่ถูกนับรวม แต่จะเก็บรายการไว้ใน `winners-summary.json` ให้ตรวจเองได้

## สัญญาณที่ควรดูต่อ

`egp flags` หารูปแบบที่คนทำงานด้านความโปร่งใสใช้เป็นจุดเริ่มต้นตรวจสอบ ทุกข้อเป็นแค่สัญญาณ ไม่ใช่หลักฐานว่ามีการทุจริต หลายรายการมีเหตุผลที่ถูกต้องตามระเบียบ เช่น ซื้อน้ำมันจากปั๊มเดียวในอำเภอ หรือซื้อยาจากองค์การเภสัชกรรม

| สัญญาณ | ดูอะไร |
|---|---|
| `split` | หน่วยงานเดียวกันจ้างผู้ชนะรายเดิม งานประเภทเดียวกัน ด้วยวิธีเฉพาะเจาะจงตั้งแต่ 3 โครงการภายใน 30 วัน แต่ละโครงการต่ำกว่าวงเงินที่ใช้วิธีนี้ได้ (500,000 บาท หรือ 100,000 บาทสำหรับวิธีตกลงราคาเดิม) แต่รวมกันแล้วเกิน รูปแบบนี้คือสิ่งที่เรียกว่าการแบ่งซื้อแบ่งจ้าง |
| `near_reference` | งานประกวดราคาที่ราคาชนะต่ำกว่าราคากลางไม่ถึง 1% แปลว่าแทบไม่มีการแข่งราคา |
| `concentration` | ผู้ชนะรายเดียวได้เงินเกินครึ่งของทั้งหน่วยงานในปีงบประมาณนั้น |
| `direct_over_cap` | วิธีเฉพาะเจาะจงที่ราคากลางเกิน 500,000 บาท ทำได้เฉพาะกรณีที่ พ.ร.บ.จัดซื้อจัดจ้างฯ 2560 มาตรา 56 กำหนด เช่น เร่งด่วน หรือมีผู้ขายรายเดียว ควรดูเหตุผลที่หน่วยงานใช้ |

ค่าตั้งต้นตัดหน่วยงานและโครงการที่ต่ำกว่า 5 ล้านบาทออก ปรับได้ด้วย `--min-baht` และดูเฉพาะผู้ชนะที่เป็นนิติบุคคล ไม่แสดงชื่อบุคคลธรรมดา

วงเงิน 500,000 บาทของวิธีเฉพาะเจาะจงมาจาก พ.ร.บ.การจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. 2560 มาตรา 56 วรรคหนึ่ง (2) (ข) กับกฎกระทรวงลงวันที่ 23 สิงหาคม 2560

## กับดักในไฟล์ทางการ

ถ้าจะใช้ข้อมูลชุดนี้เอง ไม่ว่าจะใช้เครื่องมือนี้หรือไม่ ควรรู้ไว้ก่อน

- **ชื่อชุดข้อมูลไม่เหมือนกันทุกปี** มีทั้ง `cgd-contract-2558`, `cdg-contract-2564` (สลับตัวอักษร) และ `egp-contact-2568` (contact ไม่ใช่ contract)
- **คอลัมน์ไม่เท่ากัน** ปี 2558-2567 มี 31 คอลัมน์ บางไฟล์มีคอลัมน์ว่างต่อท้ายอีก 1-6 คอลัมน์ ปี 2568 มี 28 คอลัมน์ แต่หัวตารางบางไฟล์มี 26 ชื่อ บางไฟล์มี 31 ชื่อ ต้องอ่านตามตำแหน่ง ห้ามเชื่อหัวตาราง
- **คอลัมน์สลับกัน** ปี 2568 เอาวิธีจัดซื้อไปใส่ช่อง "กลุ่มวิธีจัดซื้อฯ" และเอากลุ่มมาใส่ช่อง "วิธีจัดซื้อฯ"
- **เลขนิติบุคคลถูก Excel ทำเสีย** ปี 2558-2567 เลข 13 หลักกลายเป็น `1.05522E+11` เหลือแค่ 6 หลักแรก ส่วนบุคคลธรรมดาถูกปิดเลขท้ายเป็น `xxxx` (ตั้งใจ) ปี 2568 เลขนิติบุคคลครบ เครื่องมือนี้เก็บ 5 หลักแรกที่ยังเหลือไว้ในคอลัมน์ `winner_prefix` (สำนักงานทะเบียน ประเภทนิติบุคคล และปีที่จดทะเบียน) ใช้แยกบริษัทชื่อซ้ำกันคนละจังหวัดได้ บางหน่วยงานในปี 2559-2564 เหลือแค่ 3 หลัก (`1.06E+11`) และหลักสุดท้ายถูกปัดเศษ แถวพวกนี้จะไม่มี `winner_prefix` แล้ว `winners` จะรวมเข้ากับบริษัทชื่อเดียวกันที่มีสัญญาอย่างน้อย 90% ของชื่อนั้น
- **เลขที่สัญญาถูก Excel แปลงเป็นวันที่** เช่น `6/58` กลายเป็น `มิ.ย.-58`
- **วันที่สองแบบ** `29-ก.ค.-58` กับ `29 พ.ย. 67` เป็นปี พ.ศ. สองหลัก เครื่องมือนี้แปลงเป็น ค.ศ. แบบ `2015-07-29`
- **ไฟล์แรกๆ เป็นสัญญาใหญ่ ไฟล์ท้ายๆ เป็นงานหลักร้อยหลักพันบาท** แต่เรียงแบบคร่าวๆ เท่านั้น สัญญาหมื่นล้านยังโผล่หลังสัญญาสิบล้านได้ อย่าเอาไฟล์เดียวไปสรุปทั้งปี
- **หนึ่งโครงการมีได้หลายแถว** หนึ่งแถวคือหนึ่งสัญญา ถ้าแบ่งเป็นหลายสัญญาก็มีหลายแถว นับโครงการให้ใช้ `COUNT(DISTINCT project_id)`

## ชื่อกรรมการบริษัท

ข้อมูล e-GP ไม่มีชื่อกรรมการหรือผู้ถือหุ้น ต้องไปดูที่กรมพัฒนาธุรกิจการค้า `egp winners` ใส่ลิงก์หน้าบริษัทบน [DBD DataWarehouse](https://datawarehouse.dbd.go.th) ไว้ให้ทุกบริษัทที่มีเลขนิติบุคคลครบ เปิดดูกรรมการได้ทีละบริษัท

เครื่องมือนี้ไม่ดึงข้อมูลกรรมการอัตโนมัติ เพราะ DBD ไม่ได้เปิดให้ดึงแบบนั้น ระบบมีตัวกันบอต ช่องทาง API ทางการให้เฉพาะหน่วยงานรัฐ และกรมแถลงไว้ว่าไม่สนับสนุนการรวบรวมข้อมูลว่าใครเป็นกรรมการบริษัทไหน

## ข้อจำกัด

- มีเฉพาะสัญญาที่อยู่ในระบบ e-GP ปีงบประมาณ 2558 ถึงปีล่าสุดที่ data.go.th ปล่อย ปีใหม่ที่ชื่อชุดข้อมูลยังไม่รู้จะค้นจากชื่อเรื่องให้เอง
- ชื่อบริษัทเดียวกันสะกดได้หลายแบบ (`บจก.` กับ `บริษัท ... จำกัด`, มีหรือไม่มี `(มหาชน)`) `winners` รวมให้ แต่การค้นด้วย `--winner` ใช้การหาคำในชื่อ ควรลองหลายแบบ
- บริษัทที่เปลี่ยนชื่อจะนับแยกกัน
- บางโครงการมีสัญญาซ้ำ ผู้ชนะรายเดิม ยอดเท่าเดิม แต่เลขที่สัญญาต่างกัน (น่าจะเป็นสัญญาที่ทำใหม่) รวมแล้วเกินงบประมาณ จากที่วัด กระทบยอดรวมราว 0.01% และไม่เกิน 0.05% สำหรับผู้ชนะรายใหญ่ เครื่องมือนี้ยังนับตามที่ข้อมูลบอก
- ตัวเลขทั้งหมดมาจากที่หน่วยงานกรอกในระบบ ถ้ากรอกผิด ผลก็ผิดตาม

ข้อมูลจัดซื้อจัดจ้างจากระบบการจัดซื้อจัดจ้างภาครัฐ (e-GP) ของกรมบัญชีกลาง เผยแพร่โดยสำนักงานพัฒนารัฐบาลดิจิทัล (องค์การมหาชน) บน [data.go.th](https://data.go.th) ภายใต้สัญญาอนุญาต Creative Commons Attribution ถ้าเอาผลไปเผยแพร่ ให้อ้างที่มานี้ด้วย
